L'arrêté du 13 avril 2026 stabilise les modalités d'accès aux données pré-calculées pour les ISA 2026, introduisant une intégration complète avec la délégation unique et de nouvelles règles pour les demandes ponctuelles et massives. Ce changement a un impact opérationnel significatif pour les intermédiaires et les cabinets professionnels qui assistent les travailleurs frontaliers.

Pour déterminer le score de fiabilité fiscale, en plus des données saisies dans les Modèles ISA, des informations supplémentaires, appelées "variables pré-calculées", sont nécessaires. Ces variables sont fournies par l'Agence des Entrées et utilisées pour l'application des ISA via un programme informatique dédié.

Qu'est-ce que les variables pré-calculées ISA

En plus des données transmises via les déclarations fiscales, les contribuables concernés doivent utiliser des données supplémentaires fournies par l'Agence des Entrées. Ces données, identifiées dans la Note technique et méthodologique des variables pré-calculées, sont annexées aux décrets d'approbation et de modification des ISA applicables aux périodes fiscales concernées.

Comment demander les données pré-calculées

Avec l'arrêté du 13 avril 2026, l'Agence des Entrées a défini de manière structurée les modalités d'acquisition des "données supplémentaires" par les contribuables et les intermédiaires. Ce changement simplifie le processus d'accès aux données pré-calculées, le rendant plus efficace et intégré avec la délégation unique.

Pour les travailleurs frontaliers qui travaillent dans le canton du Ticino et résident en Italie, il est essentiel de comprendre comment ces nouvelles règles peuvent influencer leur situation fiscale. L'accès aux données pré-calculées est crucial pour déterminer correctement le score de fiabilité fiscale, qui peut avoir des répercussions sur les impôts à la source et les cotisations AVS et LPP.

Impact sur les travailleurs frontaliers

Les travailleurs frontaliers doivent être conscients des nouvelles procédures pour demander les données pré-calculées et gérer la délégation unique. Ce processus peut influencer leur déclaration de revenus et la détermination du score de fiabilité fiscale, qui à son tour peut affecter les impôts à la source et les cotisations de prévoyance.

Conclusion

Les nouvelles règles pour les données pré-calculées ISA 2026 représentent un changement significatif dans le processus de détermination du score de fiabilité fiscale. Pour les travailleurs frontaliers, il est essentiel de comprendre ces nouvelles procédures et leur impact potentiel sur leur situation fiscale. Nous recommandons de consulter un professionnel du secteur pour s'assurer de la conformité avec les nouvelles réglementations.

Points cles

Action concrète

Pour les frontaliers travaillant dans le canton du Tessin et résidant en Italie, il est essentiel de suivre une série d'étapes concrètes pour gérer correctement les données pré-calculées ISA 2026 et la délégation unique. Voici un guide étape par étape pour s'assurer d'être en règle avec les nouvelles réglementations.

Étape 1 : Vérification des données pré-calculées

La première étape consiste à vérifier quelles données pré-calculées sont nécessaires pour la détermination du score de fiabilité fiscale. Ces données sont fournies par l'Agence des Entrées et sont spécifiques à chaque 'position ISA'.

Étape 2 : Accès aux données pré-calculées

Avec l'arrêté du 13 avril 2026, l'accès aux données pré-calculées est devenu plus simple grâce à l'intégration avec la délégation unique. Les frontaliers ou leurs intermédiaires peuvent accéder aux données pré-calculées via le portail de l'Agence des Entrées.

Étape 3 : Insertion des données dans le Modèle ISA

Une fois les données pré-calculées obtenues, il est nécessaire de les insérer dans le Modèle ISA. Cette étape est cruciale pour déterminer correctement le score de fiabilité fiscale. Il est important de suivre attentivement les instructions fournies par l'Agence des Entrées pour éviter les erreurs.

Étape 4 : Vérification du score de fiabilité fiscale

Après avoir inséré les données pré-calculées dans le Modèle ISA, il est nécessaire de vérifier le score de fiabilité fiscale. Ce score peut influencer les impôts à la source et les cotisations prévisionnelles, il est donc fondamental de s'assurer qu'il est calculé correctement.

Étape 5 : Soumission de la déclaration de revenus

Enfin, il est nécessaire de soumettre la déclaration de revenus, en incluant toutes les données pré-calculées et le score de fiabilité fiscale. Il est important de respecter les délais fiscaux pour éviter les sanctions.
