Pas de rendez-vous nécessaire, vous pouvez faire votre annonce en ligne depuis chez vous en quelques minutes. Enregistrez-vous auprès de l'Office régional de placement compétent pour votre domicile — au plus tard le premier jour de chômage.

Pour vous inscrire, vous avez besoin de certains documents. Ceux-ci comprennent : la carte d'identité, le contrat de travail et le certificat de licenciement. Vous pouvez télécharger ces documents directement depuis chez vous via notre annonce en ligne sécurisée.

Voici comment faire :

1. Allez sur le site web de l'OCST et sélectionnez votre site de référence. 2. Cliquez sur le bouton « S'inscrire » et suivez les instructions. 3. Téléchargez vos documents requis. 4. Remplissez le formulaire d'inscription et envoyez-le.

⚠️ Attention : si vous avez déjà un dossier en cours auprès d'une autre caisse de chômage, vous devrez communiquer votre chômage dans les 48 heures.
